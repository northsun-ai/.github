# Contributing to Northsun

Thanks for your interest in contributing!

## Getting started

1. Check existing issues before opening a new one.
2. For anything larger than a small fix, open an issue first so we can agree on the approach.
3. Fork the repo and create a branch from `main`.

## Pull requests

- Keep PRs focused on a single change.
- Add or update tests where it makes sense.
- Make sure CI passes.
- Describe *what* changed and *why* in the PR description.
- All PRs need review before merging into `main`.

## GitHub Actions

Org policy requires every action to be pinned to a full-length commit SHA, e.g.
`uses: actions/checkout@<40-char-sha> # v4.2.2`. Tag references like `@v4` will fail.

## Reporting security issues

Please follow our [security policy](SECURITY.md). Don't report vulnerabilities in public issues.

## Code of conduct

By participating, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
